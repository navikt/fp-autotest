# 5058 Vurder fakta for arbeidstaker, frilans og selvstendig næringsdrivende

Saksbehandler avklarer ett eller flere faktatilfeller i beregningen. Tilfellene står på behandlingen og kopieres inn i bekreftelsen.

## Når kommer det

Kalkulus utleder ett eller flere `FaktaOmBeregningTilfelle`. Verifisert i ft-beregning:

- `FASTSETT_BG_KUN_YTELSE`: aktivitetsstatus er kun ytelse (`KunYtelseTilfelleUtleder`). For eksempel mor med sykepenger og ikke noe løpende arbeidsforhold.
- `VURDER_NYOPPSTARTET_FL`: søker er nyoppstartet frilanser (`NyoppstartetFLTilfelleUtleder`).
- `VURDER_AT_OG_FL_I_SAMME_ORGANISASJON`: arbeidstaker og frilanser i samme organisasjon (`ArbeidstakerOgFrilanserISammeOrganisasjonTilfelleUtleder`).

## Valg å avklare

| Valg | Alternativer | Standard | CLI |
|---|---|---|---|
| Tilfelle | kun ytelse, arbeidstaker og frilans i samme organisasjon, nyoppstartet frilanser (testdata uverifisert) | kun ytelse (mor med sykepenger, uten arbeid) | `lag_familie` `mor_arbeid` `sykepenger` (andre tilfeller: krever test) |
| Ytelse | FP, SVP (SVP ikke testet) | FP | `send_soknad` `ytelse` |

## Minste oppskrift (kun ytelse)

1. Mor uten inntekt: `mor().ytelse(YtelseDto.YtelseType.SYKEPENGER, LocalDate.now().minusMonths(9), LocalDate.now(), 462, 100).build()`. `far().build()`, `Relasjon.EKTE` og `.barn(LocalDate.now().minusDays(2))`.
2. Søknad: `lagSøknadForeldrepengerFødsel(fødselsdato, BrukerRolle.MOR).medAnnenForelder(AnnenforelderMaler.norskMedRettighetNorge(familie.far()))`.
3. `mor.søk(søknad)`. Ingen inntektsmelding.

Med CLI-en (kontrollert 2026-11-11):

```sh
verktoy/testsak.sh lag_familie '{"mor_arbeid":"sykepenger","fodt_dager_siden":2}'
verktoy/testsak.sh send_soknad '{"familie_id":"<familie_id>"}'
verktoy/testsak.sh vent_til_aksjonspunkt '{"saksnummer":"<saksnummer>","kode":"5058"}'
```

## Minste oppskrift (arbeidstaker og frilans uten inntektsmelding)

1. Mor: `InntektGenerator.ny().arbeidsforhold(LocalDate.now().minusYears(1), 300_000, arbeidsavtale(...).sisteLønnsendringsdato(LocalDate.now().minusMonths(2)).build()).frilans(25, LocalDate.now().minusYears(3), 300_000, arbeidsavtale(...).build())`. `.barn(LocalDate.now())`.
2. Søknad: `lagSøknadForeldrepengerTerminFødsel(fødselsdato, BrukerRolle.MOR).medFrilansInformasjon(OpptjeningMaler.frilansOpptjening()).medAnnenForelder(AnnenforelderMaler.norskMedRettighetNorge(familie.far()))`.
3. Ingen inntektsmelding. Testen fortsetter med `fortsettUteninntektsmeldinger()`.

## Standardløsning (kun ytelse)

```java
saksbehandler.hentAksjonspunktbekreftelse(new VurderFaktaOmBeregningBekreftelse())
        .leggTilAndelerYtelse(10000.0, Inntektskategori.ARBEIDSTAKER);
```

Etterpå: `ForeslåVedtakBekreftelse`, og beslutter godkjenner.

Andre metoder på bekreftelsen: `leggTilMaanedsinntektFL(int)`, `leggTilMottarYtelseFrilans(boolean)`, `leggTilMaanedsinntektUtenInntektsmelding(...)`, `leggTilMottarYtelse(...)`, `leggTilNyIArbeidslivet(...)`, `leggTilVurdertLønnsendring(...)`, `leggTilVurderTidsbegrenset(...)`, `settSkalHaBesteberegningForKunYtelse(boolean)`.

## Fallgruver

- Frilans alene gir ikke 5058. `Fodsel`-testen med arbeidsforhold og frilans (`.frilans(...)` og `.medFrilansInformasjon(OpptjeningMaler.frilansOpptjening())`) får 5038, ikke 5058.
- Uverifisert: nøyaktig hvilke testdata som gir `VURDER_NYOPPSTARTET_FL` eller `FASTSETT_MAANEDSINNTEKT_FL`. Ingen test bruker `leggTilMaanedsinntektFL` eller `leggTilMottarYtelseFrilans`.
- `BeregningVerdikjede#ATFL_samme_org...` sjekker ikke hvilket tilfelle som kommer. `arbeidsforhold(...)` og `frilans(...)` uten arbeidsgiver trekker hver sin organisasjon med `TestOrganisasjoner.tilfeldigOrg()`, som fjerner orgen fra lista. Samme organisasjon krever overloaden med `ArbeidsgiverDto`. Uverifisert hvilket tilfelle testen gir.
- Bekreftelsen må ha data fra behandlingen. Bruk `hentAksjonspunktbekreftelse`, ikke `new` direkte i `bekreftAksjonspunkt`.
